TestPulse API Integration Guide

Purpose: API reference for implementing the TestPulse app in Google AI Studio.

Generated for the deployed Spring Boot API. Do not expose JWT, database, SMTP, or other secrets in frontend code.

Base URL

https://testpluse-production.up.railway.app

For local Docker testing:

http://localhost:8081

Authentication

Login

POST /api/auth/login?mobileNumber={mobileNumber}&password={password}

Successful response contains a JWT token:

{
  "token": "eyJhbGciOiJIUzI1NiJ9...",

For protected APIs, send:

Authorization: Bearer YOUR_JWT_TOKEN

Generate Custom Test

This endpoint reads matching questions from MySQL, randomly selects the requested number, and returns the test. It does not save the generated test or questions.

Request

POST /api/tests/custom
ParameterRequiredValues / example
subjectYesMathematics
questionCountNo1 to 100; default 10
difficultyNoEASY, MEDIUM, HARD; default MEDIUM
modeNoPRACTICE, EXAM; default PRACTICE
langNoen or hi; default en
POST https://testpluse-production.up.railway.app/api/tests/custom?subject=Mathematics&questionCount=10&difficulty=MEDIUM&mode=PRACTICE&lang=en

No request body is required.

Subscription Plans

Get Plans

GET /api/subscription-plans

This endpoint is public and does not require JWT authentication.

Response

[
  {
    "id": "monthly_basic",
    "planCode": "BASIC_MONTHLY",
    "title": "Basic Monthly",
    "subtitle": "Practice tests and question access",
    "durationDays": 30,
    "originalAmountInPaise": 49900,
    "discountedAmountInPaise": 29900,
    "displayPrice": "₹299",
    "displayOriginalPrice": "₹499",
    "discountPercentage": 40,
    "badge": "Popular",
    "isRecommended": true,
    "features": [
      "Unlimited practice tests",
      "Detailed explanations",
      "Progress tracking"
    ]

]

Amount fields are in paise. Divide by 100 to display the amount in rupees. Use displayPrice when the UI should show the server-formatted price.

Create Plan (Admin)

POST /api/subscription-plans
Content-Type: application/json
Authorization: Bearer ADMIN_JWT_TOKEN
{
  "id": "monthly_basic",
  "planCode": "BASIC_MONTHLY",
  "title": "Basic Monthly",
  "subtitle": "Practice tests and question access",
  "durationDays": 30,
  "originalAmountInPaise": 49900,
  "discountedAmountInPaise": 29900,
  "displayPrice": "₹299",
  "displayOriginalPrice": "₹499",
  "discountPercentage": 40,
  "badge": "Popular",
  "isRecommended": true,
  "features": ["Unlimited practice tests", "Detailed explanations"]
}

The id, planCode, and title are required. durationDays must be greater than zero and price values cannot be negative.

Update Plan (Admin)

PUT /api/subscription-plans/{id}
Content-Type: application/json
Authorization: Bearer ADMIN_JWT_TOKEN

Use the same JSON body as create. The path {id} must identify an existing plan. The response is the updated plan object.

Delete Plan (Admin)

DELETE /api/subscription-plans/{id}
Authorization: Bearer ADMIN_JWT_TOKEN
{
  "message": "Plan deleted successfully"
}
The GET endpoint is available to the app's pricing screen. Create, update, and delete are restricted to users with the ADMIN role. A normal user token returns HTTP 403.

Forgot Password

Request OTP

POST /api/auth/forgot-password
Content-Type: application/json
{
  "email": "user@example.com"
}

Response:

{
  "message": "Password reset OTP sent to your email."
}

The backend creates a six-digit OTP, stores only its hash, sends it by email, and expires it after 10 minutes. A 60-second request cooldown is applied.

Reset Password

POST /api/auth/reset-password
Content-Type: application/json
{
  "email": "user@example.com",
  "otp": "123456",
  "newPassword": "NewPassword123"
}
{
  "message": "Password reset successfully."
}

The OTP is single-use. The new password must contain at least 8 characters.

Google AI Studio Frontend Rules

  • Keep the API base URL in one environment/config value.
  • Store the JWT in the app's secure storage, not in source code.
  • Send the Bearer token only to protected endpoints.
  • Do not send Markdown code fences in JSON requests.
  • For custom tests, render questions from the response; do not expect a saved test ID to be fetchable later.
  • Use correctOptionIndex only after the user submits an answer; do not reveal it during the question view.
  • Handle HTTP 400, 401, 403, and 500 responses with user-friendly messages.

Example JavaScript Call

const params = new URLSearchParams({
  subject: "Mathematics",
  questionCount: "10",
  difficulty: "MEDIUM",
  mode: "PRACTICE",
  lang: "en"
});

const response = await fetch(
  `${API_BASE_URL}/api/tests/custom?${params}`,
  { method: "POST" }
);

if (!response.ok) throw new Error("Unable to generate test");
const customTest = await response.json();

Error Behavior

StatusMeaning
400Invalid parameters, unsupported mode/difficulty, or not enough matching questions.
401JWT missing or invalid for a protected endpoint.
403User is authenticated but does not have the required role.
500Unexpected server or database error.
